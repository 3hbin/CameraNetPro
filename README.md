# Camera Nét Pro AI (tối ưu Huawei Y9 2019)

App camera có chế độ AI giống stock Huawei.

## Chế độ AI
- AI Auto
- Làm đẹp (Beauty)
- Chân dung
- Đêm
- Đồ ăn
- Phong cảnh

+ Bộ lọc, tỷ lệ, timer, zoom, quay video, chụp liên tục, nụ cười tự chụp...

## Build bằng GitHub
1. Tạo repo mới trên github.com
2. Upload toàn bộ nội dung trong SharpCamera.zip
3. Vào Actions → đợi build xong → tải APK ở Artifacts
